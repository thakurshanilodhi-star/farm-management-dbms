# Farm Management System (DBMS)

A web-based Farm Management System built with Flask, HTML/CSS, and MySQL to manage farmer registration, farm records, agricultural products, sales/orders, and transaction history.

## Features
- Farmer Management: Register farmers and view farmer details.
- Agro Products & Sales: Manage agricultural products, stock/pricing, and record product sales.
- Records & Reporting: View consolidated operational and transaction records backed by MySQL queries.

## Tech Stack
- Backend: Python, Flask, mysql-connector-python
- Database: MySQL
- Frontend: HTML5, CSS3 (Jinja2 templates)
